# To-Do List

## About the Project

This is a simple To-Do List web app made using HTML, CSS, and JavaScript. It allows users to add tasks, mark them as completed, and delete them.

## Features

* Add new tasks
* Mark tasks as completed
* Green check mark for completed tasks
* Uncheck completed tasks
* Delete tasks
* Simple and clean user interface

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run the Project

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
